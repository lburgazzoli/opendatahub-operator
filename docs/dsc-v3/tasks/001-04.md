## Lifecycle and precondition

`001-02.md` and `001-03.md`. Update metadata and Outcomes before work. This

## Implementation

2. Remove residual generated v1 references from fixtures, samples, CRDs,

   unstructured fixture only for a named non-odh-cli repository test.
3. Mark v2 `served: true`, `storage: false`, `deprecated: true`, with DEC-019's

4. Regenerate ODH/RHOAI CRDs, patches, webhook manifests, bundles/CSVs, API
   docs, deepcopy/object code, samples, and RBAC if affected.
5. Require generated CRDs to serve only v2/v3, store only v3, omit v1, expose
   `/convert` through v2, and use ConversionReview protocol `[v1]`.
