# DSC-V3-004: Freeze the AI Hub contract

## Lifecycle

Read `../development.md`, `../decisions.md`, `../PLAN.md`, and `../TASKS.md`;
update metadata and execution Outcomes when starting. Do not resolve naming or
defaulting by inference. Record owner-approved behavior in `../decisions.md`
first. Complete this task only after the contract is exact and locally
self-contained.

## Objective

Define the public v3 AI Hub contract and its lossless mapping to the v2 Model
Registry API while preserving the existing internal module identity.

## Existing behavior and unresolved proposal

- V2 uses `components.modelregistry`, DSC status `modelregistry`, and condition
  `ModelRegistryReady`.
- The latest proposal renames the public v3 field to `components.aiHub`; an
  older description says `hub`. Neither is authoritative until owners accept
  one exact name.
- V2 defaults an empty managed `registriesNamespace` to
  `odh-model-registries` or `rhoai-model-registries`, depending on the build,
  and keeps the namespace immutable while managed.
- The handler projects `registriesNamespace` to internal
  `instancesNamespace`, falling back to the applications namespace when empty,
  and mirrors the namespace into legacy DSC status.
- DEC-011 requires the internal GVK `AIHub`, resource `default-aihub`, module
  and manifest name `modelregistry`, and related metadata to stay unchanged in
  3.6.

Proposed, not yet accepted:

```yaml
components:
  aiHub:
    managementState: Managed
    registriesNamespace: model-registry
```

## Required decision

Obtain and record:

1. Final public JSON and Go names; exact spec/status paths and ready condition.
2. Namespace optionality and behavior for absent, empty, defaulted, and custom
   values for both ODH and RHOAI builds.
3. Defaulting versus handler fallback, validation, immutability, warnings, and
   update behavior in `Managed` and `Removed` states.
4. Field-by-field v2 -> v3 and v3 -> v2 mappings for spec, status, conditions,
   and legacy status compatibility.
5. V2 read-modify-write preservation and every required direct/round-trip test.
